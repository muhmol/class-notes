# یادداشت کلاس / Class Notes

اپ وب نصب‌پذیر (PWA) برای ثبت سریع آنچه سر کلاس گفته شد: «استاد گفت» و «من انجام دادم»، با تاریخ و ساعت خودکار.

## اجرا

```bash
npm install
npm run dev       # توسعه: http://localhost:5173
npm test          # اجرای تست‌ها (Vitest)
npm run build     # بررسی تایپ + ساخت نسخه‌ی نهایی در dist/
npm run preview   # اجرای نسخه‌ی ساخته‌شده (سرویس‌ورکر و حالت آفلاین فقط اینجا و روی نسخه‌ی نهایی کار می‌کنند)
```

نیاز به Node.js 20 یا بالاتر.

## دیپلوی روی GitHub Pages

با هر push و pull request، تست‌ها اجرا و پروژه بیلد می‌شود. فقط push به شاخه‌ی `main` اپ را منتشر می‌کند (`.github/workflows/deploy.yml`). اگر تست یا بیلد خراب شود، دیپلوی انجام نمی‌شود.

1. مخزن **عمومی** (public) در GitHub بساز، بدون README و بدون `.gitignore`.
2. در Settings → Pages، گزینه‌ی Source را روی **GitHub Actions** بگذار.
3. کد را push کن (دستورها در توضیح پروژه).
4. آدرس اپ: `https://<نام‌کاربری>.github.io/<نام‌مخزن>/`

مسیر پایه از نام مخزن خودکار ساخته می‌شود (`BASE_PATH`). برای تست محلی زیر همان مسیر:

```bash
BASE_PATH=/class-notes/ npm run build
BASE_PATH=/class-notes/ npm run preview
```

## ساختار

```
src/
  lib/db.ts         داده‌ها (IndexedDB با Dexie): درس‌ها و یادداشت‌ها
  lib/i18n.ts       متن‌های فارسی و انگلیسی
  lib/dates.ts      نمایش تاریخ و ساعت شمسی یا میلادی
  lib/settings.ts   زبان، ظاهر، آخرین درس (localStorage)
  lib/pwa.ts        سرویس‌ورکر، آماده‌بودن آفلاین، دکمه‌ی نصب
  pages/            خانه، درس‌ها، جزئیات درس، مرور، تنظیمات
  components/       ناوبری، یادداشت، تایم‌لاین، فرم درس
```

## نکته‌هایی برای مرحله‌ی همگام‌سازی

- هر درس و یادداشت از اول `id` یکتا (UUID) و `updatedAt` دارد.
- حذف یادداشت «نرم» است (`deletedAt`)، تا حذف هم بتواند همگام شود.
- زمان‌ها به‌صورت epoch ذخیره می‌شوند و فقط موقع نمایش شمسی یا میلادی می‌شوند.
- قاعده‌ی تداخل: آخرین ویرایش (`updatedAt` بزرگ‌تر) برنده است.

## نسخه‌ی بعد

ثبت‌نام با ایمیل و رمز، تایید ایمیل با کد یک‌بارمصرف، فراموشی رمز، همگام‌سازی با سرور و نمایش وضعیت سینک.
